# Chatify

A real-time chat app built with React (plain JavaScript), Vite and Tailwind CSS,
plus **N**: a news feed (any country, any category) with a live chat under every story.
The backend is a small Node + Express + Socket.io server with SQLite.

```bash
npm install
npm run dev   # starts the website and the API server together
npm test
```

Runs locally. News comes from Google News RSS, which is for personal, non-commercial use only.

See `.claude/skills/chatify/SKILL.md` for the stack, folder layout and conventions.
